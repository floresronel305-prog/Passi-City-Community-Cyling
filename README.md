# PASSI CITY COMMUNITY CYCLING

Community cycling web app: live GPS on real roads, routes (Agcararao, San Enrique, Compi, Man-it Bypass), chat, membership, bike form, photo upload, profile, settings and admin panel.

## Files
- `index.html` - pages and structure
- `style.css` - design and animations
- `app.js` - main system
- `enhancement.js` - extra features
- `logo.png` - add the official Passi City logo here

## Setup
1. Put `logo.png` in this folder.
2. In `app.js`, set the `EMAILJS` keys (emailjs.com) so the forgot-password code is sent to Gmail.
3. Change the admin password in `app.js` (`ADMIN`).
4. Adjust the route coordinates in `ROUTES` if needed.
5. Upload to GitHub, then Settings > Pages > Deploy from branch (main). Location needs HTTPS, which GitHub Pages provides.
